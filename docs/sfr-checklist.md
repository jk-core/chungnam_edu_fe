# SFR 반영 점검표 (SFR-004-01 ~ SFR-028-03)

요구사항정의서 원문(`충청남도 교육청 태양광 진단 플랫폼.xlsx`, G열)을 한 줄씩 훑어
프론트엔드 반영 여부와 위치를 적는다. 2026-08-05 기준, 총 185건.

## 판정 기준

| 표기 | 뜻 |
|---|---|
| **반영** | 화면에서 동작한다. 목업 데이터를 쓰지만 API 만 갈아 끼우면 된다 |
| **부분** | 프론트 몫은 있으나 요구 문구의 일부가 빠졌다 — 사유를 적는다 |
| **반영(표시)** | 판정·연산은 서버 몫이고, 그 결과를 화면이 요구대로 보여 준다 |
| **서버** | 수집·연산·모델 학습 등 서버 몫. 화면 산출물이 없다 |
| **미반영** | 해당 화면·기능이 없다 |

집계: **반영 151**(그중 결과 표시 7) · **부분 5** · **서버 29** · **미반영 0**

일부 줄은 성격이 같은 항목을 묶었다(`012-01~04` 등). 묶음까지 펼치면 185건 전부를 덮는다.
