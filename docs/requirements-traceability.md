# 요구사항 추적표

요구사항정의서(576건)의 프론트엔드 구현 현황을 추적한다.
화면 소스의 `NavChild.requirements` 배열과 이 표는 같은 ID 체계를 쓴다.

- **구현**: 목업 데이터 기반으로 화면·동작이 실동작한다. API 연동 시 `mocks/`·스토어 셀렉터만 교체하면 된다.
- **부분**: 프론트 몫(표시·조작)만 구현했고, 판정·수집 등 서버 몫은 범위 외.
- **범위 외**: 화면 산출물이 없는 요구사항 — 하단 별도 절에 사유를 남긴다.

## 5. API 전환 지점

화면은 전부 셀렉터·목업 함수만 호출한다. 실제 API 로 갈 때 고치는 곳:

- `src/mocks/*.ts` — 조회 데이터 생성부를 fetch 로 교체
- `src/stores/*Store.ts` 의 `merge*()` — 시드/오버레이 병합을 서버 응답으로 교체
- `src/mocks/today.ts` — `TODAY` 앵커를 실시간으로 전환
