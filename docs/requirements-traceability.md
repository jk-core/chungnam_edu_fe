# 요구사항 추적표

요구사항정의서(576건)의 프론트엔드 구현 현황을 추적한다.
화면 소스의 `NavChild.requirements` 배열과 이 표는 같은 ID 체계를 쓴다.

- **구현**: 목업 데이터 기반으로 화면·동작이 실동작한다. API 연동 시 `mocks/`·스토어 셀렉터만 교체하면 된다.
- **부분**: 프론트 몫(표시·조작)만 구현했고, 판정·수집 등 서버 몫은 범위 외.
- **범위 외**: 화면 산출물이 없는 요구사항 — 하단 별도 절에 사유를 남긴다.

## 0. 사이트맵 (2026-08-04 회의 확정)

```
홈
발전관리 ── 발전통계 / 운전이력 / 현장보고서
AI진단  ── 발전진단 / 월간보고서 / 알림이력
이용안내 ── 공지사항 / Q&A
별도(헤더·드롭다운): 통합관제, 교육용 대시보드, 관리자 콘솔, 마이페이지
```

화면을 줄이면서도 요구사항 기능은 흡수처를 정해 옮겼다. 옛 주소는 `routesList.tsx` 의
리다이렉트가 새 주소로 넘긴다 — 북마크와 문서 링크가 죽지 않게 하려는 것이다.

| 사라진 화면 | 흡수처 |
|---|---|
| 기간별 통계 / 학교별 비교 / 환경 기여도 | 발전통계 (일·월·연 토글, 요약 카드) |
| 수집데이터 트렌드 조회 / 원시 데이터 | 운전이력 계측 표 |
| 수집 현황 | 관리자 콘솔 › 데이터 품질 |
| 점검 일정 | 현장보고서 하단 |
| 알림 목록·미조치·타임라인·설정 (4화면) | 알림이력 한 화면 |

## 5. 의도된 이탈

요구사항 문구와 다르게 구현한 것. 빠뜨린 것이 아니라 정하고 벗어난 것이라 근거를 남긴다.

### SFR-009-02 — 설비 상태 라벨

원문은 「최소 5개 이상의 기준으로 상세 구분 EX) 가동중 / 준비중 / 발전저하 / 발전이상 / 통신장애 등」이다.
**단계 수(5)는 충족**하고 라벨만 다르게 간다.

| 코드 | 요구사항 예시 | 구현 |
|---|---|---|
| 7001 | 준비중 | 준비중 |
| 7002 | 가동중 | **정상** |
| 7003 | 발전저하 | **주의** |
| 7004 | 발전이상 | **경고** |
| 7998 | 통신장애 | **통신단절** |

`EX)`·`등` 이라 예시로 읽고, 사내 다른 발전 모니터링 프로젝트가 쓰는 어휘로 맞췄다 —
**설비 상태와 알림 구분이 한 축을 쓰기 때문이다.** 알림은 이 축에서 7003·7004·7998 만 받는데,
설비를 「발전저하」라 부르고 알림을 「주의」라 부르면 같은 코드가 화면마다 다른 말로 뜬다.
「발전저하」는 통신단절에도 걸려 뜻이 겹치기도 한다.

화면 문구는 `mocks/status.ts` 의 `OPERATION_LABEL` 하나에서 나온다 — 발주처가 원문 어휘를
요구하면 그것만 고치면 된다. `configs/codes.ts` 의 `ZodStatusCode.NAME` 은 BE 가 내려주는
`statusName` 을 검증하는 zod enum 이라 화면 문구가 아니다 — 여기를 고치면 응답 검증만 깨진다.
예외로 통합관제 장애 판의 묶음 제목만 7998 을 「데이터 미수신」이라 부른다
(`ControlRoom/components/FaultGroups.tsx` · 2026-08-25 사업팀 회의).

`docs/SFR_반영점검표.xlsx` 의 「반영」 칸은 원문 예시 어휘를 그대로 둔다 — `EX)` 는 예시라
문구까지 맞추는 것이 요구가 아니다. 단계 수와 구분 기준이 요구이고 그것은 충족한다.

## 6. API 전환 지점

화면은 전부 셀렉터·목업 함수만 호출한다. 실제 API 로 갈 때 고치는 곳:

- `src/mocks/*.ts` — 조회 데이터 생성부를 fetch 로 교체
- `src/stores/*Store.ts` 의 `merge*()` — 시드/오버레이 병합을 서버 응답으로 교체
- `src/mocks/today.ts` — `TODAY` 앵커를 실시간으로 전환
- `.env` 의 `VITE_KAKAO_MAP_KEY` — 카카오맵 JavaScript 키. 비우면 내장 SVG 지도로 동작한다
  (외부망에서 지도 API 호출이 가능한지는 발주처 확인 중)
